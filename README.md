## Описание

Приложение представляет собой расширенную версию Московского транспортного портала на основе ЛР3. Добавлены: страница калькулятора для расчёта параметров маршрутов, 3D-модель транспортного средства (Three.js), страница автора с информацией о разработчике.

## Функциональность

### Каталог транспорта
- Отображение транспортных средств в виде карточек
- Детальный просмотр каждого транспорта
- Отрисовка через JS с использованием DOM API

### Калькулятор маршрутов
- JS-логика калькулятора реализована в `script.js` (window.onload)
- Расчёт параметров для оптимизации маршрутов транспорта

### 3D-просмотрщик
- Three.js для отображения интерактивных 3D-моделей транспортных средств
- Поддержка GLB/GLTF форматов

### Компоненты
- **ProductCardComponent** — карточка транспортного средства
- **ProductComponent** — детальная информация о транспорте
- **BackButtonComponent** — кнопка возврата
- **ThreeDViewerComponent** — 3D-просмотрщик моделей

### Навигация
- Главная страница (`MainPage`) — каталог карточек
- Страница товара (`ProductPage`) — детали транспорта
- Страница калькулятора (`CalculatorPage`) — расчёт маршрутов
- Страница автора (`AuthorPage`) — информация об авторе

## Структура файлов

```
/index.html                 — корневой HTML (SPA)
/main.js                    — точка входа
/script.js                  — JS-логика калькулятора (window.onload)
/style.css                  — стили приложения
/pages/                     — страницы
  /main/index.js            — главная страница (каталог)
  /main/data.js             — данные карточек
  /product/index.js         — страница деталей
  /calculator/index.js      — страница калькулятора
  /author/index.js         — страница автора
/components/                — компоненты
  /product-card/index.js    — карточка транспорта
  /product/index.js         — детальная информация
  /back-button/index.js     — кнопка возврата
  /three-d-viewer/         — 3D-просмотрщик
/glbmodels/                 — 3D-модели (.glb файлы)
/media/                     — медиафайлы
```

## Технологии

- HTML5, CSS3
- Vanilla JavaScript (DOM API)
- Bootstrap 5 (подключён через npm)
- Three.js (3D-модели)

## Запуск

Установите зависимости и запустите dev-сервер:

```bash
npm install
npx vite        # → http://localhost:5173
```

Альтернативно откройте `index.html` через VS Code + расширение **Live Server**.
