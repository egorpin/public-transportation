# public-transportation

Московский транспортный портал. ЛР2 (calculator_js) — калькулятор с JS-логикой.

## Структура

```
calculator.html   — страница калькулятора
script.js         — JS-логика (script.js)
author.html       — страница автора
index.html        — главная
style.css         — стили
media/            — медиафайлы
```

## Запуск

Открыть `calculator.html` через VS Code + Live Server, либо напрямую в браузере.

## Описание

Калькулятор на JS. Поддерживает: сложение, вычитание, умножение, деление, квадрат, смена знака, процент, очистка. Вывод меняет цвет в зависимости от результата.
