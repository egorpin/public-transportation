## Описание

Приложение представляет собой калькулятор для расчёта стоимости проезда на общественном транспорте Москвы. Реализовано с помощью HTML-разметки и CSS-стилей. JavaScript не используется — логика калькулятора описана только на уровне верстки.

## Функциональность

### Калькулятор
- Статичные HTML/CSS кнопки калькулятора
- Дисплей для отображения результата
- Стилизованные кнопки операций: `C`, `+/-`, `%`, `/`, `x`, `-`, `+`, `=`
- Цифровые кнопки `0–9` и точка

### Страница автора
- Информация о разработчике приложения
- Ссылка на профиль GitHub

### Навигация
- Главная страница (`index.html`)
- Страница калькулятора (`calculator.html`)
- Страница автора (`author.html`)

## Структура файлов

```
/index.html         — главная страница
/calculator.html    — страница калькулятора
/author.html         — страница автора
/style.css           — стили приложения
/media/              — медиафайлы
```

## Запуск

Откройте `index.html` в любом современном браузере. Рекомендуется использовать VS Code + расширение **Live Server** для автоматического обновления страницы.
