## Описание

Приложение представляет собой REST API сервер для Московского транспортного портала. Сервер обрабатывает CRUD-операции над карточками транспортных средств, хранит данные в формате JSON и обеспечивает персистентность между перезапусками.

## Функциональность

### API эндпоинты
- Получение списка всех карточек транспорта
- Получение одной карточки по ID
- Создание новой карточки
- Обновление существующей карточки
- Удаление карточки по ID

### Хранение данных
- Данные хранятся в файле `src/data/transport.json`
- Персистентность между перезапусками сервера
- Валидация входящих данных

### Обработка ошибок
- Корректные HTTP-статусы для каждого сценария
- JSON-ответы с описанием ошибок

## Структура файлов

```
/src/
  /controllers/           — обработчики маршрутов
  /routes/                — определения API (/transport)
  /services/              — бизнес-логика, чтение/запись JSON
  /data/
    transport.json        — данные карточек транспорта
  index.js                — точка входа, запуск сервера
/package.json             — зависимости и скрипты
```

## API

| Метод  | Путь                | Описание                   |
|--------|---------------------|----------------------------|
| GET    | `/transport`        | Получить все карточки      |
| GET    | `/transport/:id`    | Получить карточку по ID    |
| POST   | `/transport`        | Создать новую карточку     |
| PATCH  | `/transport/:id`    | Обновить карточку по ID    |
| DELETE | `/transport/:id`    | Удалить карточку по ID     |
