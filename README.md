## Описание

Приложение представляет собой калькулятор для расчёта стоимости проезда на общественном транспорте Москвы с полной JS-логикой. Поддерживает базовые арифметические операции и расширенные функции: смена знака, вычисление процента, возведение в квадрат. Дисплей меняет цвет в зависимости от результата вычисления.

## Функциональность

### Калькулятор
- Базовые арифметические операции: сложение, вычитание, умножение, деление
- Возведение в квадрат (`x²`)
- Смена знака числа (`+/-`)
- Вычисление процента (`%`)
- Очистка (`C`)
- Форматирование вывода результата
- Динамическая смена цвета дисплея в зависимости от результата

### Страница автора
- Информация о разработчике приложения
- Ссылка на профиль GitHub

### Навигация
- Главная страница (`index.html`)
- Страница калькулятора (`calculator.html`)
- Страница автора (`author.html`)

## Структура файлов

## Запуск

Откройте `calculator.html` в любом современном браузере. Рекомендуется использовать VS Code + расширение **Live Server** для автоматического обновления страницы.
