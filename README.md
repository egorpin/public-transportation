# public-transportation

Московский транспортный портал. ЛР1 (calculator) — HTML/CSS калькулятор.

## Структура

```
calculator.html   — страница калькулятора
author.html       — страница автора
index.html        — главная
style.css         — стили
media/            — медиафайлы
```

## Запуск

Открыть `index.html` через VS Code + Live Server, либо напрямую в браузере.

## Описание

Статичные HTML-страницы. Калькулятор — верстка на HTML + CSS, без JS-логики. Страница автора содержит информацию о разработчике.
